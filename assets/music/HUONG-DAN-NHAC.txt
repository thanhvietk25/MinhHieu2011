HƯỚNG DẪN THÊM NHẠC (đặt file vào thư mục này: assets/music/)

Có 3 bản nhạc, đều là file .mp3:

1) background.mp3  - nhạc nền của cả trang (đang có sẵn).
2) memories.mp3    - nhạc khi bấm "Xem kỷ niệm". Đóng phần kỷ niệm thì nhạc nền tự phát lại.
3) birthday.mp3    - nhạc khi mở phòng bánh sinh nhật bí mật. Đóng phòng thì nhạc nền tự phát lại.

Cách làm: đổi tên file nhạc của bạn đúng như trên (chữ thường, không dấu, không khoảng trắng)
rồi chép vào thư mục này. Muốn đổi tên file khác thì sửa dòng "const MUSIC = {...}" trong js/script.js.

Chưa có memories.mp3: bấm "Xem kỷ niệm" vẫn nghe nhạc nền như cũ.
Chưa có birthday.mp3: phòng bánh dùng giai điệu Happy Birthday tự tạo bằng code.

Lưu ý:
- Nên dùng mp3 khoảng 128 kbps, mỗi bài dưới 5 MB để trang tải nhanh trên điện thoại.
- Sau khi thay file, nhấn Ctrl + F5 để trình duyệt tải lại bản mới.
- Đưa lên GitHub nhớ upload cả các file mp3.
